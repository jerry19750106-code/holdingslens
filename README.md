# 持倉透鏡 HoldingsLens

**把組合的「風險來源」拆開算給你看——不預測漲跌，只回答你的風險押在哪裡。**

1024 造物挑戰投稿作品。輸入持倉金額（或直接填基金代碼），30 秒內拿到一張「風險帳單」：
風險貢獻歸因、危機壓力測試、結構健康評分、優化模擬、分享卡。

## 在線演示

https://jerry19750106-code.github.io/holdingslens/

## 它回答什麼問題

| 痛點 | 殘酷現實 | 本工具的回答 |
|---|---|---|
| 持倉檔數 ≠ 分散程度 | 名義買了 10 檔，實際全押同一類資產 | 風險貢獻歸因 + 有效押注數 ENB，把相關性納入分散度量 |
| 危機時相關性飆升 | 平時分散，股債齊跌時才發現是假分散 | 危機壓力測試：相關性只准升、不准降，數學保證危機波動 ≥ 平常波動 |
| 報告全是黑箱 | 工具給一個分數，沒人說得清怎麼來的 | 每個數字對應一條公式，全部可展開 |

## 數學核心

```
協方差矩陣    Σᵢⱼ = ρᵢⱼ · σᵢ · σⱼ
組合波動率    σp = √(wᵀΣw)
邊際風險      MCRᵢ = (Σw)ᵢ / σp
風險貢獻      RCᵢ = wᵢ · MCRᵢ   （ΣRCᵢ = σp，恆等閉合）
有效持倉數    N_eff = 1 / Σwᵢ²
有效押注數    ENB = min(N_eff, 1/(wᵀCw))   （相關性修正赫芬達爾倒數）
```

## 工程事實

- **零依賴**：單文件 HTML，無服務器、無構建、斷網可用；持倉資料不上傳。
- **可驗證**：126 項引擎不變量測試全綠，含危機鐵律 5000 組隨機場合、
  「加入防禦資產不得降分」性質測試（84 組對照 + 2000 組隨機，0 次違例）。
- **三端同一引擎**：H5 / 微信小程序 / Node 腳本共用一份 UMD 引擎（位元組級一致）。
- **簡繁雙語**：引擎層產出，非 UI 字串替換。
